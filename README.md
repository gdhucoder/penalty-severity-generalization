# Penalty Severity Generalization

This repository is the designated code-release location for the study:

**Cross-Department Generalization in Administrative Penalty Severity Classification: Evaluating Outcome-Excluded and Outcome-Inclusive Text Settings**

The article has been accepted for publication in *IEEE Access* and is in production. Its assigned DOI is **10.1109/ACCESS.2026.3747805**. A link to the published article will be added when available.

## Release status

The study code is not yet publicly available. Following publication of the article and subject to institutional approval, the author plans to release sanitized code, experimental configurations, and reproduction instructions in this repository.

The planned release includes:

- preprocessing and anonymization code;
- duplicate-safe IID and leave-one-department-out split generation;
- model-training and controlled-baseline configurations;
- aggregate-analysis and figure-generation code;
- environment specifications and reproduction instructions.

## Data availability

The processed record-level dataset and private manual-audit materials are not available for redistribution. No credentials, local paths, or potentially identifying information will be included in an authorized release.

The article provides aggregate statistics needed to evaluate its findings. Reproducing the reported record-level experiments would require authorized access to the underlying data and corresponding data splits.
