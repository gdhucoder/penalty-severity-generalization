# Penalty Severity Generalization

This repository is the designated code-release location for the study **“Cross-Department Generalization in Administrative Penalty Severity Classification: Evaluating Outcome-Excluded and Outcome-Inclusive Text Settings.”**

## Release status

The reproducibility package is being prepared for a possible post-acceptance release, subject to institutional review. The study code and record-level data are not publicly available at this time.

## Planned contents

Subject to authorization, the repository will contain:

- sanitized preprocessing and anonymization code;
- duplicate-safe IID and leave-one-department-out split generation;
- model-training and controlled-baseline configurations;
- aggregate-analysis and figure-generation code;
- environment specifications and reproduction instructions.

## Data availability

No record-level administrative penalty data, private manual-audit material, credentials, local paths, or potentially identifying information will be included in any authorized release.
